# Noura Salah Akar — Portfolio

A responsive personal portfolio website built for the **First Practical Assignment: Professional Portfolio Website**.

## Built with
- HTML5
- CSS3 (custom styles in `css/style.css`)
- [Bootstrap 5.3](https://getbootstrap.com/) and Bootstrap Icons
- Google Fonts (Poppins and Inter)

## Sections
- **Home**: introduction, photo and social links
- **About**: short bio and quick facts
- **Skills**: front-end skills, tools and soft skills
- **Projects**: sample projects with descriptions and links
- **Resume**: education, experience and certificates timeline
- **Contact**: contact details and a message form

## Project structure
```
noura-portfolio/
├── index.html
├── css/
│   └── style.css
├── assets/
│   └── images/
└── README.md
```

## Run locally
Open `index.html` in a browser, or start a local server from this folder:

```bash
python -m http.server 5500
```

Then visit http://localhost:5500.
